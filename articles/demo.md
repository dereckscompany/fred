# Demonstrating fred

## Introduction

This vignette demonstrates the example function in `fred`:

1.  [`add()`](https://dereckscompany.github.io/fred/reference/add.md) -
    A simple R function to add two numbers

``` r

box::use(fred[ add ])
```

## Using the add() function

The [`add()`](https://dereckscompany.github.io/fred/reference/add.md)
function is a simple R function that adds two numbers:

``` r

add(2, 3)
#> [1] 5
add(10.5, 20.3)
#> [1] 30.8
add(-5, 5)
#> [1] 0
```
